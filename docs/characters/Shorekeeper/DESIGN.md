# Shorekeeper - Kit Design (v2)

## Fantasy

Shorekeeper is the Black Shores' archivist - cold, analytical, watching outcomes unfold before
they happen. She doesn't fight in the moment; she's already accounted for it. The kit should feel
like **setting up a prediction, then cashing it in for something disproportionate.**

v2 renames the mechanics to match her actual Wuthering Waves kit instead of generic placeholders.
Reads far more "her" and gives sharper card-naming to work from once you're in the editor.

## Core mechanics

### 1. Stellarealm (persistent field - was "Beacon")
A custom status on herself, matching her Resonance Liberation field in the source game. Applied
once early (starter relic or a cheap 0-cost starter Skill: **"Cast Stellarealm"**). While active:
- Passive Effect: small Block to Shorekeeper (and, if you decide co-op should share it, allies)
  every turn - the "ambient field" hum.
- **Escalation**: after a set number of her own Skills are played while it's active, Stellarealm
  upgrades in place from *Elementary* to **Sophisticated Stellarealm** (a second, stronger custom
  status that replaces the first) - mirrors the real kit's Elementary→Sophisticated evolution.
  Sophisticated version doubles the Block/heal pulse and unlocks the "Discernment" payoff below.
- Several cards branch on `Stellarealm Active` / `Sophisticated Stellarealm Active` as a condition.

### 2. Collapsed Cores (resource stacks - was "Prediction")
A custom stack-scaled status. Basic Attacks generate Collapsed Cores on hit (matches her real
Basic Attack effect exactly). Cores are the currency her Skills and Powers spend for amplified
effects - the visible number you build toward a payoff, same design role as Acheron's crit stacks.

### 3. Discernment (signature Rare Attack - her Intro Skill)
Only playable while **Sophisticated Stellarealm** is active (playability condition). Guaranteed
"critical" framing - mechanically: consumes all Collapsed Cores, deals damage scaling with cores
spent, always triggers her Power-card synergies that key off "the last card was Discernment."
This is her single most build-defining card - the moment the setup pays off.

### 4. Star Butterflies (token cards - her signature summons)
Two named tokens, matching Flare/Dim Star Butterfly:
- **Dim Star Butterfly** (token, cheap) - deals small AoE Spectro-flavored damage, generated by a
  couple of her Skills.
- **Flare Star Butterfly** (token, rarer) - on play, pulses Stellarealm early instead of dealing
  damage; a defensive/support token for when you need the field pulse *now*, not on schedule.

## Card pool structure (target: 85+, matching Acheron's scope)

| Type | Rarity split (rough) | Count target |
|---|---|---|
| Attack | 2 Basic / 10 Common / 8 Uncommon / **3+ Rare** | ~24 |
| Skill | 2 Basic / 10 Common / 8 Uncommon / **3+ Rare** | ~24 |
| Power | 1 starter / 6 Common / 6 Uncommon / **2+ Rare** | ~16 |
| Token cards | Dim/Flare Star Butterfly + 4–6 more | ~6–8 |
| Ancient (starting-deck only) | flavor cards | 2–4 |

Shop-crash rule still applies: **≥2 Rare Attacks, ≥2 Rare Skills, ≥1 Rare Power**, or the compiler
silently fills gaps with generic filler - cover these first.

### Representative cards (fill out the rest around this spine)

**Attacks**
- *Collapsed Strike* (Basic, starter) - small hit, generates 1 Collapsed Core.
- *Speculative Data* (Common) - hit + generate Core; Otherwise-branch does more if Stellarealm
  is active.
- *Actual Data* (Uncommon) - consumes 2 Cores for bonus damage (partial payoff, cheaper than
  Discernment, for decks that can't always reach Sophisticated Stellarealm).
- **Discernment** (Rare, signature - see above).
- *End Loop* (Rare) - AoE hit that also refreshes Stellarealm's duration/re-triggers its pulse.

**Skills**
- *Cast Stellarealm* (Basic, starter) - apply Elementary Stellarealm.
- *Resonance Pulse* (Common) - Block + generate 1 Core, counts toward the Sophisticated upgrade
  threshold.
- *Coordinated Recovery* (Uncommon) - heal + apply a stack of a minor "Marked" debuff to an enemy
  (setup for Attacks that check for Marked targets).
- *Field Correction* (Rare) - big Block + immediately triggers the Stellarealm pulse regardless of
  timer.

**Powers**
- *Archive Discipline* (Common) - passive: generate +1 Core the first time you play a Skill each
  turn.
- *Elementary Forecast* (Uncommon) - passive: Stellarealm's pulse also draws a card.
- **Prophecy** (Rare, Ultimate-tier, X-cost) - damage scales with Collapsed Cores spent, also
  pulses Stellarealm for a big heal on resolve. The card the whole kit points at.

## Qualia Archive - the meta-progression hook

Unchanged in spirit from v1, still the piece worth the extra Path-B effort:
- Earn a small Qualia amount from specific triggers (first Stellarealm pulse per combat, playing
  Discernment, killing a Marked enemy).
- Spend at rest sites on permanent-for-this-run **Archive Entries**: Stellarealm pulses twice,
  Collapsed Core cap +2, Prophecy cost –1, Sophisticated threshold –1, etc.
- Needs a custom rest-site UI panel + a save-hook (`SpireField` on player/save state) - this is
  code, not card-editor content, and is the main reason to stay on Path B.

## Multi-character architecture (for expanding to other WuWa characters later)

Plan the code layout now so adding a second character (Zhezhi, Jinhsi, Changli, etc. - whoever's
next) doesn't mean untangling Shorekeeper-specific code first:

- Keep **shared, reusable pieces** (a generic "field/stance" base status, a generic "resource
  stack that gets spent for scaling damage" base status, shared UI plumbing for a rest-site
  upgrade panel) in a small internal shared library inside this same repo or as its own BaseLib-
  dependent shared project - don't hardcode Shorekeeper-only names into anything that isn't
  actually Shorekeeper-specific.
- Each character gets its **own subfolder** (`Shorekeeper/`, later `Zhezhi/`, etc.) with its own
  card/relic/status definitions, referencing the shared base pieces rather than duplicating them.
- Qualia Archive could stay per-character (separate resource per character, on-theme) or become a
  shared cross-character system later - decide this once a second character is actually in scope,
  don't over-engineer it now.
- Keep this repo as the container for the whole "WuWa cast in STS2" project rather than spinning up
  a new repo per character - matches how you've structured GOH Toolkit as one repo covering many
  related tools rather than fragmenting.

## Open design questions to lock before building card #1

- Exact numbers (damage/block/energy costs) - needs a balance pass once a few of these exist
  in-game to compare against vanilla STS2 characters' power curve.
- Collapsed Core cap (e.g. max 5) vs. uncapped with diminishing returns.
- Co-op behavior: does Stellarealm buff allies too, or self-only? Several cards above assume
  self-only for now - flag if you want party-wide from the start, it changes multiple designs.
